**Cheeky Foveated DLSS v0.4.1**

- **AFW eye-tracking cadence:** keeps the SR and NR crop dimensions fixed while gaze, smoothing, tracking fallback and source-eye metadata move the foveated region. This prevents eye movement from repeatedly recreating DLSS features and their temporal histories.
- **DLSS-NR resource stability:** reuses completed NR resources when frame textures rotate, gives the alignment border a lightweight reusable path and caches shader bytecode. This removes the repeated codec and border setup that caused frame-time spikes with AFW eye tracking.

**Updating:** Exit the game before replacing files:

- **ReShade:** Copy the new `CheekyFoveatedDLSS.addon64` over the existing add-on in the game's executable folder.
- **UEVR:** Unzip the complete UEVR package into the game's UEVR configuration directory, for example `%APPDATA%\UnrealVRMod\HogwartsLegacy`. Preserve the `plugins/` and `scripts/` layout and update both DLLs and the Lua script together. Your saved settings can stay in place. When moving from ReShade to UEVR, uninstall ReShade with its installer and remove the Cheeky add-on.

**OpenXR:** Run the matching `CheekyOpenXRSetup.exe` for ordinary OpenXR stereo alignment/calibration or OpenXR eye tracking. DLSS-NR requires a compatible `nvngx_dlssnr.dll`, supplied separately.
