**Cheeky Foveated DLSS v0.5.2**

This update improves cached NVIDIA DLSS runtime discovery and automatic eye-calibration recovery, with smaller fixes to foveation defaults and diagnostics since v0.5.1.

- **Cached DLSS runtime support:** standalone and UEVR integrations can use compatible DLSS runtimes cached by NVIDIA App overrides across DX11, DX12 and Vulkan instead of requiring every runtime beside the game executable.
- **DX11 runtime selection:** fixes cached DLSS hook installation and selects the correct runtime for the DX11-to-DX12 transport path, improving Super Resolution and Ray Reconstruction behavior when several runtime candidates are present.
- **Automatic calibration recovery:** Auto calibration no longer stalls indefinitely when a corner capture is incomplete; it advances through its retry and fallback policy.
- **Neutral vertical offset:** new configurations now default the vertical foveation offset to zero. Existing saved settings are preserved.
- **Bounded exception diagnostics:** first-chance exception reporting is capped so repeated exceptions cannot grow diagnostics without limit.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately or available through a compatible NVIDIA App runtime override.
