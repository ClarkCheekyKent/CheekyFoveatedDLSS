**Cheeky Foveated DLSS v0.6.0**

This update adds experimental OpenXR frame generation for D3D11 and D3D12 games, adds quad-view DLSS support for DCS and MSFS 2024, and brings the headset menu to quad-view and FG sessions since v0.5.5.

- **Experimental DLSS Frame Generation (2x):** open **DLSS-FG** in F8 (standalone) or **LuaLoader → Cheeky Foveated DLSS** (UEVR) and check **Enable DLSS Frame Generation (2x)**. FG works in D3D11 and D3D12 OpenXR stereo sessions with native DLSS depth and motion-vector guides, and requires compatible NVIDIA hardware and the updated OpenXR layer. FG is off by default. The center can use **DLSS**, **Simple motion-vector warping** or **Bidirectional interpolation**, and the periphery has its own scale and method. **Foveated frame generation** can match the DLSS-SR region and gaze placement or use its own region, with an optional blue border to check it. When both regions use shader methods, D3D11 games use a native D3D11 path with no D3D12 bridge. D3D11 games that need DLSS use Cheeky's private DX12 transport automatically, even with foveated SR off.
- **FG pacing and diagnostics:** **Advanced settings** holds the pacing clock, the FG GPU queue, **Release game rendering** (including **Never (display clock only)** for GPU-bound scenes), output destination and an opt-in latency timeline. Keep **Release game rendering** at **After generated frame submission** (the default) for serialized frame matching. The FG tab shows total, generated and fallback frames, unique output FPS, frame latency and per-stage GPU timings. The top of the menu now shows CPU, GPU, video encode and VRAM load, which also appear in the log. The presenter never resubmits unchanged frames.
- **Quad views for DCS and MSFS 2024:** the OpenXR layer now provides fixed quad views over the headset's stereo view for D3D11 games such as DCS. It also recognizes D3D12 games such as MSFS 2024 that composite four DLSS views themselves. Center views use the center preset and supersampling over the full view, and peripheral views use the peripheral preset and input scale. NR applies to the center views only, and D3D11 NR needs DX11 → DX12 transport. **Stereo / Gaze** shows quad-view assignment with **Automatic** or **Manual** roles, optional view numbers, and saved manual layouts. DCS renumbers its views after a mission change and retries unresolved assignments. FG also runs in quad-view sessions. **Wait for quad-view composition (DX12)** is on by default; turn it off to let MSFS return from `xrEndFrame` without waiting for the GPU.
- **Headset menu:** the F8 headset menu now appears in quad-view and FG sessions, and in MSFS 2024, whose mirror uses a Streamline D3D12 proxy. A new **VR controllers and hands control the menu** option (on by default) lets you drive the menu with only the desktop mouse and keyboard.
- **Clearer naming and diagnostics:** Peripheral DLAA is now **Peripheral DLSS**, and the periphery scale is described as 20%–100% of the game's DLSS input size. **View details** shows evaluation calls, the API, eye mapping, the focus/periphery role and the latest input and output sizes for each DLSS handle. The standalone Diagnostics tab has a new layout, and the **All settings** tab has been removed.
- **Stability:** fixes MSFS 2024 freezing on recenter. Fixes ACC through OpenComposite aborting with `XR_ERROR_SESSION_NOT_RUNNING` when it loads a map with FG on. NVIDIA depth-bounds and UAV-overlap calls now run under the D3D11 device lock to avoid driver races. Hook rescans now run only when the game's loaded modules change, plus a periodic safety check, which removes a constant background import scan.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place. Open **LuaLoader → Cheeky Foveated DLSS** and check **Enable Cheeky for this game** if the profile has not been enabled yet. You can install it as a global plugin by placing it in the `%AppData%\UnrealVRMod\UEVR` folder.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking. FG and quad views require this updated layer; replace the runtime and the OpenXR layer together.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately or available through a compatible NVIDIA App runtime override.
