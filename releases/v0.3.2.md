**Cheeky Foveated DLSS v0.3.2**

- **Stereo calibration fixes:** improves recognition of distorted markers, adds support for R11G11B10 HDR textures and correctly handles vertically flipped eye submissions, keeping gaze and automatic alignment in the correct coordinates.
- **UEVR compatibility fixes:** restores OpenVR eye tracking when the game initializes OpenVR before the plugin loads. Also fixes OpenXR eye calibration and gaze mapping when UEVR's Virtual Desktop workaround adds a dummy projection layer.
- **Lower calibration overhead:** samples immediately when enabled, then every 10 VR frames while keeping the established eye mapping active. Changes in eye assignment can take up to 10 frames plus readback latency to detect.
- **Native DLSS sizing fix:** preserves the correct output dimensions and current render region when games reuse DLSS parameters for optimal-settings queries, addressing incorrect foveation dimensions.
- **Independent DLSS-NR eye tracking:** allows the foveated NR region to follow gaze even when SR foveation is disabled, with its own region size.
- **Improved diagnostics:** adds D3D12 calibration texture formats, failure stages and error codes to help investigate remaining calibration issues.

**Updating:** Close the game and follow the instructions for your integration:

- **ReShade:** Replace CheekyFoveatedDLSS.addon64 in the game's executable folder.
- **UEVR:** Extract the complete UEVR ZIP into the game's UEVR configuration directory—not the game's installation folder. For example, Hogwarts Legacy uses %APPDATA%\UnrealVRMod\HogwartsLegacy. Merge the plugins and scripts folders and replace existing files, including both plugin and runtime DLLs. Keep your existing settings. If switching from ReShade, uninstall it using the ReShade installer and remove CheekyFoveatedDLSS.addon64 if present.

**OpenXR users must also run the new CheekyOpenXRSetup.exe**, including users with the v0.3.0 or v0.3.1 layer, to receive the updated calibration support and UEVR Virtual Desktop fix. Native OpenVR games do not require the OpenXR installer.
