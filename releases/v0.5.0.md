**Cheeky Foveated DLSS v0.5.0**

This release brings a lot of changes and may need hotfixes soon after release. If you run into issues, try the previous release.

- **Standalone integration:** adds a standalone option that does not require ReShade, with an F8 settings overlay for DLSS, stereo alignment and eye tracking. This gives you another way to use Cheeky when ReShade conflicts with other mods.
- **More VR mod support:** adds DLSS routing for R.E.A.L. VR and improves handling of wrapped DX12 graphics resources. Cheeky preserves the mod's full-frame DLSS calls while running its own foveated processing through the underlying NVIDIA runtime.
- **Experimental DX12 Ray Reconstruction foveation:** adds separate center and peripheral RR processing, with independent histories and Game default / D / E / F preset selections. The periphery remains denoised, DLSS-NR can run before or after RR, and unsupported inputs retain the game's full-frame RR path. Game and headset validation remains limited.
- **Automatic eye calibration overhaul:** maps gaze into headset views cropped from a larger render, including the layouts used by R.E.A.L. VR. Auto calibration tries lightweight corner markers first, then timing-tolerant captures and a wider crop search when needed. It learns the successful method per game to improve later calibration attempts.
- **Less ongoing calibration work:** adds a mode that retains full crop-search calibration until the views, dimensions or VR session change, avoiding continued marker stamping and image readbacks. Corner methods continue validating. Use **Recalibrate now** if the crop or eye assignment changes without a corresponding view change.
- **Mixed graphics APIs and delayed stereo submission:** improves calibration across D3D11 and D3D12, asynchronous OpenXR submissions, alternating-eye rendering and shared mono sources. Vulkan sources transferred into D3D11 OpenXR submissions also gain calibration support; native Vulkan VR submissions remain unsupported.
- **OpenXR eye tracking:** lets Cheeky request runtime gaze even when the game does not request it itself. Also fixes simulated gaze, gaze-history resets at the jump threshold and unnecessary fixed-gaze history resets during automatic stereo alignment.
- **AFW compatibility:** fixes standalone eye mapping and calibration with AFW and allows Ray Reconstruction foveation while AFW is loaded.
- **Native Vulkan support:** adds a Vulkan processing path and settings overlay, with the layer DLL and manifest included in the standalone ZIP.
- **Mod loader compatibility:** adds `version.dll` as an alternative to `dxgi.dll`, optional chaining to another mod's `dxgi2.dll`, and safeguards against VRPerfKit forwarding loops. DX12 now uses the lower DLSS hook by default, leaving upstream core and Streamline calls intact; changing the hook setting requires a restart.
- **DLSS-NR and graphics stability:** improves DX11 DLSS-NR and stereo transport stability, reuses transport resources across fovea resizes, and improves discovery of nested NVIDIA runtimes. Direct3D shaders are now precompiled instead of compiled during gameplay.
- **Controls and diagnostics:** moves Cheeky's UEVR controls into a named script panel, improves standalone overlay input, adds calibration timing and capture diagnostics, and adjusts alignment-border and marker brightness for exposure.

**Updating:** Exit the game before replacing files:

- **Standalone:** Copy the `CheekyFoveatedDLSS/` folder and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also copy `CheekyVulkanLayer.dll` beside the game executable and preserve `CheekyFoveatedDLSS/Vulkan/`. Use F8 to open the settings overlay. When moving from ReShade to standalone, uninstall ReShade with its installer and remove the Cheeky add-on.
- **UEVR:** Unzip the complete UEVR package into the game's UEVR configuration directory, for example `%APPDATA%\UnrealVRMod\HogwartsLegacy`. Preserve the `plugins/` and `scripts/` layout and update both DLLs and the Lua script together. Your saved settings can stay in place. When moving from ReShade to UEVR, uninstall ReShade with its installer and remove the Cheeky add-on.

**OpenXR:** Run the matching `OpenXR/CheekyOpenXRSetup.exe` included in your ZIP for ordinary OpenXR stereo alignment/calibration or OpenXR eye tracking. DLSS-NR requires a compatible `nvngx_dlssnr.dll`, supplied separately.
