**Cheeky Foveated DLSS v0.3.0**

- **UEVR plugin:** adds a dedicated integration with controls inside UEVR, including expandable settings groups, per-group resets, performance diagnostics and support ZIPs. Sliders apply on release. Remove ReShade from the game when using the UEVR plugin.
- **Automatic eye calibration:** follows marked DLSS outputs to the submitted left and right eyes, correcting assignments when loading videos, menus or scene changes reorder views. Runs asynchronously every frame on D3D11 and D3D12 with OpenVR or OpenXR, including packed images and texture arrays. Diagnostics show corrections applied and calibration cost.
- **Broader late-injection support:** adopts existing DLSS features after UEVR injection and improves interception of cached NGX and Streamline calls. Compatibility still depends on the game and available frame data.
- **GPU timing improvements:** improves command-list tracking and recovery from discarded recordings, with clearer timing diagnostics.
- **DLSS-NR updates:** searches for `nvngx_dlssnr.dll` beside the running game executable as well as the plugin runtime. Defaults the NR working scale to 1.0 for improved stability. DLSS-NR remains experimental.
- **Simpler setup:** separates ReShade and UEVR installation instructions and renames the shared layer installer to **CheekyOpenXRSetup.exe**. It supports stereo alignment and eye calibration as well as eye tracking.

**Updating:** Close the game. For ReShade, replace **CheekyFoveatedDLSS.addon64**. For UEVR, remove ReShade from the game, then extract the complete UEVR ZIP into the game's UEVR configuration directory, replacing both plugin DLLs and the Lua script. Keep your existing settings.

**OpenXR users must also run the new CheekyOpenXRSetup.exe**, even if an older Cheeky layer is already installed and even without an eye-tracked headset. This updates the shared layer in place. Native OpenVR games such as ACC in SteamVR mode need no OpenXR installer. Manual stereo offsets are not a reliable substitute for calibration across scene changes.
