**Cheeky Foveated DLSS v0.6.2**

This update fixes DCS freezing when frame generation is reset, adds DLSS-G preset selection, and improves DLSS-NR HDR color and GPU resource cleanup since v0.6.1. Frame generation remains experimental and off by default.

- **DCS frame generation stability:** fixes a freeze when disabling or resetting frame generation, including with VDXR. Frame timing no longer accumulates excessive lead in fast-running menus, and returning to native rendering correctly waits for the runtime clock to catch up.
- **DLSS-G preset selection:** choose **Preset A**, **Preset B**, or **Preset C** in the standalone or UEVR frame generation menu. **Preset C** is the default, including for existing profiles and Reset FG defaults. It requests Lite candidate blending and requires DLSS-G **310.9.16 or newer**. The preset applies to every region using DLSS-G. Preset B requests UI recomposition, which requires separate HUD-less scene and UI inputs; without those inputs it behaves like A.
- **DLSS-NR HDR color:** normalizes NR inputs using the game's exposure and preserves HDR color information to correct NR color handling.
- **DLSS-NR resource cleanup:** reuses temporary input textures within command recordings, safely retires resources when command allocators reset, and reclaims cached resources when NR is disabled. Adds bounded resource-pool diagnostics for support reports.

**Known issues:** the **DLSS Vectors** interpolation methods can still cause ghosting or doubling in some games. Use **DLSS-G** in affected games.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place. Open **LuaLoader → Cheeky Foveated DLSS** and check **Enable Cheeky for this game** if the profile has not been enabled yet. You can install it as a global plugin by placing it in the `%AppData%\UnrealVRMod\UEVR` folder.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking. The DCS timing fix and DLSS-G preset selection require the updated layer; replace the runtime and the OpenXR layer together.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately or available through a compatible NVIDIA App runtime override.
