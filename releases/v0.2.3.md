# Cheeky Foveated DLSS v0.2.3

- **Native SteamVR / OpenVR support:** adds automatic stereo alignment, runtime gaze, and built-in simulated gaze for supported OpenVR games, including ACC. No OpenXR layer is needed for this path.
- **Quest 3 automatic alignment:** uses headset projection geometry without eye-tracking hardware. Real gaze still requires an eye-tracked headset and compatible runtime.
- **Reduced logging:** stops repeated submission messages for unchanged OpenVR eye textures.

**Updating:** Close the game and replace `CheekyFoveatedDLSS.addon64`. For OpenXR games, also close OpenXR games and run the matching `CheekyEyeTrackingSetup.exe`. OpenXR games still need the layer when SteamVR is their OpenXR runtime; native OpenVR games do not need it or the development mock driver.

Eye tracking and DLSS-NR remain experimental; compatibility varies by game.
