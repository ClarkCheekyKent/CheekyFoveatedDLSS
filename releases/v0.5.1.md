**Cheeky Foveated DLSS v0.5.1**

This update adds in-headset standalone controls and fixes Ray Reconstruction, controller input and automatic eye-calibration recovery since v0.5.0.

- **In-headset SteamVR menu:** the standalone settings overlay now appears as a floating, curved panel in native OpenVR/SteamVR games using D3D11 or D3D12. Use a VR controller to point, click, drag and scroll, or use the desktop mouse to move and resize the same window.
- **In-headset OpenXR menu:** adds a settings panel for D3D11 and D3D12 OpenXR sessions, including support for sharing the menu between different graphics devices. Install the matching OpenXR layer included in the package.
- **Configurable menu key:** change the standalone overlay hotkey in the new **General** tab. F8 remains the default, and the tab includes a **Reset to F8** option.
- **Eye tracking while adjusting settings:** gaze and simulated gaze continue while Cheeky's own SteamVR menu captures controller input, as long as scene frames and gaze samples remain valid. The SteamVR dashboard still pauses this behavior.
- **R.E.A.L. VR controller input:** fixes OpenXR menu controller actions in R.E.A.L. VR sessions that do not attach or synchronize their own input actions, including headsets without eye tracking.
- **Ray Reconstruction fixes:** fixes Streamline RR interception and center cropping of depth-stencil inputs used by RR.
- **Automatic calibration recovery:** after losing an eye mapping, automatic calibration retries lightweight corner methods before falling back to the full search. Repeated recovery requests no longer continually restart the discovery budget.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer. The new standalone headset panels still need broader testing in real games and headsets; Vulkan headset menus are not included.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately.
