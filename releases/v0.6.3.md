**Cheeky Foveated DLSS v0.6.3**

This update adds chained DLSS-NR model passes and NR preset selection, updates optical-flow frame generation, and brings compatibility and smoothness fixes since v0.6.2. Frame generation remains experimental and off by default.

- **Up to three DLSS-NR passes:** **Model passes** now lets you run 1–3 passes in Direct3D 12 and DX12 Transport. Each extra pass refines the previous pass's output inside the same region and costs about one more NR evaluation.
- **DLSS-NR (DLSS5) preset selection:** choose **Default**, **Preset A (Original)**, or **Preset B (Faster)** Preset B requires the new NR **310.9.16 or newer**.
- **Optical-flow frame generation:** Improve OptiFlow framegen to reduce artifacts.
- **SPT-VR compatibility:** fixes Direct3D 11 processing and automatic eye calibration for the texture formats used by SPT-VR. Tested with SPT-VR 1.3.0.
- **Smoother OpenXR input:** limits repeated startup input diagnostics and keeps the log open, removing recurring diagnostic file-open bursts that could hitch UEVR and REFramework games every few seconds.
- **Loader compatibility:** the `version.dll` and ASI loaders now load an existing local `dxgi.dll` proxy before starting Cheeky's host when DXGI has not already loaded. This preserves other mods such as ReShade, Special K and VR mods in games that load DXGI late.
- **AFW gaze allocation:** fixes an unnecessarily wide foveated allocation when the source eye is initially unknown. The allocation adjusts once when the source eye becomes available and stays stable through later metadata loss.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place. Open **LuaLoader → Cheeky Foveated DLSS** and check **Enable Cheeky for this game** if the profile has not been enabled yet. You can install it as a global plugin by placing it in the `%AppData%\UnrealVRMod\UEVR` folder.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking. Update the runtime, menu script and OpenXR layer together for the optical-flow changes.

**DLSS-NR runtime:** download the [DLSS-NR archive](https://d1oqksizpb0e3d.cloudfront.net/rtx-remix-ngx_sdk_dlnr@2.7z), extract `lib\Windows_x86_64\rel\nvngx_dlssnr.dll`, and copy that DLL into the game folder where the other DLSS files are. DLSS-NR remains experimental and off by default.
