# Cheeky Foveated DLSS v0.2.2

- **OpenXR crash fix:** fixes a potential crash when accessing eye-tracking data after the OpenXR layer unloads.
- **Automatic stereo centering:** aligns the fovea using available OpenXR or Streamline projection data, reducing the need for per-game stereo offset adjustments. Height offset remains adjustable.
- **DX12 compatibility and eye tracking:** improves eye-view matching, supports more DLSS output texture layouts, and fixes cropped Streamline handling.
- **DLSS-NR fixes:** corrects crop/output handling and makes NR follow the DLSS-SR position, with optional linked size and shape.
- **Version in the UI:** the add-on panel now shows the installed version.

**Updating:** Replace `CheekyFoveatedDLSS.addon64` in your game folder. If you use the OpenXR layer, close your OpenXR games and run the new `CheekyEyeTrackingSetup.exe` too—this release requires the matching updated layer for OpenXR alignment and gaze. Fixed foveation alone only needs the add-on.

Eye tracking and DLSS-NR remain experimental; compatibility varies by game.
