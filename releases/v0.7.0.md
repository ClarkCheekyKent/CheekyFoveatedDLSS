**Cheeky Foveated DLSS v0.7.0**

This update adds **Universal DLSS 5**, bringing DLSS-NR to stereo OpenXR games without native DLSS, with or without frame generation. It also improves D3D11 optical-flow performance and removes runtime shader compilation stalls since v0.6.3. DLSS-NR and frame generation remain experimental and off by default.

- **Universal DLSS 5:** run DLSS-NR in games without native DLSS, with or without frame generation. Select **Apply at → Headset output (Universal DLSS 5)**. Supports D3D11/D3D12 stereo OpenXR; quad views keep the game's NR route.
- **Flexible NR inputs:** use optical flow, game DLSS motion/depth, or zero vectors and flat depth. Reuse FG's optical flow when available, or capture game DLSS guides with FG off.
- **Faster D3D11 frame generation:** batches GPU work, reduces flushes and moves optical flow to a private device where supported to reduce interference with game rendering.
- **Fewer shader stalls:** precompiled Direct3D shaders eliminate compilation pauses during rendering.
- **Cleaner menus and transport fixes:** reorganizes UEVR controls, hides unavailable game-DLSS options and fixes OpenXR compatibility with DX12 Transport.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place. Open **LuaLoader → Cheeky Foveated DLSS** and check **Enable Cheeky for this game** if the profile has not been enabled yet. You can install it as a global plugin by placing it in the `%AppData%\UnrealVRMod\UEVR` folder.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking. Universal DLSS 5 requires the updated layer even with frame generation disabled. Update the runtime, menu script and OpenXR layer together.

**DLSS-NR runtime:** download the [DLSS-NR archive](https://d1oqksizpb0e3d.cloudfront.net/rtx-remix-ngx_sdk_dlnr@2.7z), extract `lib\Windows_x86_64\rel\nvngx_dlssnr.dll`, and copy that DLL into the game folder where the other DLSS files are. In games without DLSS, place it beside the game executable.
