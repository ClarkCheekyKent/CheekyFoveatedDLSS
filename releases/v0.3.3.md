**Cheeky Foveated DLSS v0.3.3**

- **Pre-Upscale DLSS-NR processing mode:** adds neural rendering before upscaling via selector in UI. Thank you to @Williem3 for adding this support!
- **DLSS-NR stability and motion fixes:** corrects motion-vector units across processing orders and input routes, improves guide handling, isolates resets and safely manages cached resources across command-list replay. Reduces VRAM use and preserves the composited DLSS-SR result when NR fails.
- **Verified DLSS-NR controls:** replaces the old preset hints with Standard, Natural and Cinematic styles, constrains intensity to its verified range and shows skin-structure and paper-white controls only when their required inputs are active.
- **DLSS-NR shortcut:** Adds a new **Alt+Shift+'>'** shortcut that toggles DLSS-NR while preserving its foveation setting.
- **Stereo eye calibration:** uses spatial marker patterns for more reliable left/right-eye recognition when individual calibration markers are distorted or partially ambiguous. (Fixes for heavily post processed games like Mortal Shell 2)

**Updating:** Close the game and follow the instructions for your integration:

- **ReShade:** Replace CheekyFoveatedDLSS.addon64 in the game's executable folder.
- **UEVR:** Extract the complete UEVR ZIP into the game's UEVR configuration directory—not the game's installation folder. For example, Hogwarts Legacy uses `%APPDATA%\UnrealVRMod\HogwartsLegacy`. Merge the plugins and scripts folders and replace existing files, including both plugin and runtime DLLs. Keep your existing settings. If switching from ReShade, uninstall it using the ReShade installer and remove CheekyFoveatedDLSS.addon64 if present.

**OpenXR users also run the new CheekyOpenXRSetup.exe** to keep the installed layer matched to this release.
